# CLAUDE.md - Instrucoes para o Claude Code

## Git Workflow

- **Sempre** desenvolver na branch `claudecode`. Nunca criar outras branches.
- **Nunca** fazer merge para `main` nem push para `main` sem autorizacao explicita do usuario.
- Fluxo: commit na `claudecode` → push para `origin/claudecode` → aguardar usuario autorizar merge para `main`.
